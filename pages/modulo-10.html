▶️ Scripts Disponíveis

Treinamento Playwright — Do Zero ao Primeiro Teste

O package.json define scripts de atalho para os comandos mais usados no dia a dia.

Scripts principais

npm test

Roda todos os testes em modo headless (sem abrir o navegador visualmente). Mais rápido e indicado para CI/CD.

npm test
npm run test:headed

Roda os testes com o navegador visível. Ideal para acompanhar o que está acontecendo durante o desenvolvimento.

npm run test:headed
npm run test:ui

Abre a interface gráfica do Playwright. Ideal para depurar testes visualmente — você pode pausar, avançar passo a passo e inspecionar cada ação.

npm run test:ui
npm run test:report

Abre o relatório HTML do último teste. Mostra prints de tela, erros e duração de cada teste.

npm run test:report

Comandos extras úteis via npx

# Filtra e roda um teste específico pelo nome
npx playwright test --grep "nome do teste"

# Roda apenas em um navegador
npx playwright test --project=chromium

# Modo debug passo a passo
npx playwright test --debug

# Grava ações e gera código automaticamente (Codegen)
npx playwright codegen https://site.com
🎯
Dica pro: O npx playwright codegen é uma ferramenta poderosa para iniciantes — ele abre o navegador e grava todas as suas ações, gerando o código de teste automaticamente. Ótimo para aprender a sintaxe!
