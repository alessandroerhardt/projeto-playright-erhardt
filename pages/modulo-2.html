📋 Pré-requisitos

Treinamento Playwright — Do Zero ao Primeiro Teste

Antes de começar a instalação do Playwright, certifique-se de que seu ambiente atende aos requisitos abaixo.

Sistema Operacional

  • 🪟 Windows 10/11
  • 🍎 macOS 12 (Monterey) ou superior
  • 🐧 Linux — Ubuntu 20.04 ou superior

Software necessário

  • Node.js versão 18 ou superior
  • npm — instalado automaticamente com o Node.js
  • VS Code — editor recomendado
  • Git — opcional, mas altamente recomendado

Verificando se o Node.js já está instalado

Abra o terminal e execute:

node --version
npm --version

Se os comandos retornarem versões (ex: v20.11.0 e 10.2.4), você já está pronto para o próximo passo.

⚠️
Atenção: Se o Node.js não estiver instalado ou a versão for inferior à 18, siga o Módulo 5 — Instalando o Node.js antes de continuar.
